# 参考文档目录

本目录用于存放 todo Skill 的详细参考资料。

本 Skill 是 skill-starter 的端到端教学示例，逻辑足够简单（add/list/done 三命令），主要讲解已集中在 `SKILL.md` 和仓库教程 [07 带脚本 Skill](../../../04-创建Skill/07-带脚本-Skill.md)。

适合放这里的内容：

- 如果未来给 todo 加复杂功能（如按标签过滤、优先级），把详细规则写在这里。
- 边界条件说明、输出格式样例。

不适合放这里的内容：

- 当前任务状态 → `TASKS.md`
- 变更历史 → `CHANGELOG.md`
- 路线图 → `ROADMAP.md`
- 关键决策 → `DECISIONS.md`
