# 项目路线图

> Last updated: 2026-07-30

## 项目愿景

做一个**教学问题最清晰**的带脚本型 Skill 标准示例：用最少的代码讲清「触发、契约、脚本、退出码、错误路径、测试」这条完整链路，让学习者照着就能理解一个真实 Skill 长什么样。

这不是一个要做成产品的待办应用，而是 skill-starter 课程体系的端到端样例。

## 阶段状态速览

| 阶段 | 目标摘要 | 当前状态 | 备注 |
| :--- | :--- | :--- | :--- |
| 阶段一 | 跑通 add/list/done 三命令 + 契约 + 错误路径 | ✅ 完成 | 0.1.0 |
| 阶段二 | 真实 Agent 触发验证（应触发/不应触发/正常/错误） | ⚪ 待开始 | 对应仓库 TASKS T-008，需可隔离的 Agent 环境 |
| 阶段三 | 作为「从复制到发布」逐步实验的唯一案例 | ⚪ 待开始 | 对应仓库 TASKS T-009 |

## 阶段二

- [ ] 在无旧会话上下文的真实 Agent 环境测试四类场景（应触发 / 不应触发 / 正常执行 / 错误输入），保存输入、实际行为和判断依据。
- [ ] 失败场景回写为改进项，不掩盖近失误。

## 阶段三

- [ ] 以本 Skill 为唯一案例，编写「复制 → 改写 → 运行 → 测试 → 版本 → 发布 → 回滚」逐步实验，每步有预期结果和失败恢复。
