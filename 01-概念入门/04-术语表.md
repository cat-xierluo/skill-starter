# 术语表

本文档收录 AI 编程领域的常用术语，帮助你快速入门。本表随教程更新持续增补，新术语首次出现在哪篇就补进这里。

## A

| 术语 | 英文 | 解释 |
|------|------|------|
| Agent | Agent | AI 智能体，能自主决策和执行任务的 AI 程序 |
| API | Application Programming Interface | 接口，程序之间对话的「电话」 |
| Artificial Intelligence | AI | 人工智能，让机器具有人类智能 |

## B

| 术语 | 英文 | 解释 |
|------|------|------|
| Baseline | Baseline | 基线，评测或对比时的参照版本，后续改动都跟它比（见 04-创建Skill/09） |
| Branch | Branch | 分支，代码开发的平行工作线 |
| Bug | Bug | 程序错误、缺陷 |

## C

| 术语 | 英文 | 解释 |
|------|------|------|
| CI | Continuous Integration | 持续集成，每次提交自动跑测试和构建，及早发现问题（见 02-工具指南/10） |
| CLI | Command Line Interface | 命令行界面，文字输入的操作系统交互方式 |
| Clone | Clone | 克隆，把远程仓库复制到本地 |
| Cloud | Cloud | 云，基于互联网的远程服务器 |
| Commit | Commit | 提交，代码的存档点 |
| Container | Container | 容器，封装软件运行环境的轻量级虚拟化技术 |
| Conflict | Conflict | 冲突，两个改动无法自动合并时出现的问题 |

## D

| 术语 | 英文 | 解释 |
|------|------|------|
| 依赖 | Dependency | 你的项目运行需要用到的别的库或包，装错了就跑不起来（见 02-工具指南/08-09） |
| Debug | Debug | 调试，修复程序错误 |
| Deploy | Deploy | 部署，把代码发布到服务器上线运行 |
| Developer | Developer | 开发者，写程序的人 |

## E

| 术语 | 英文 | 解释 |
|------|------|------|
| 环境变量 | Environment Variable | 存在系统里的命名值，程序运行时用来读配置（如 API 密钥、路径）（见 02-工具指南/08-09） |
| Eval | Eval | 评测，用一组测试题量化 AI 或 Skill 表现的过程（见 04-创建Skill/09） |
| 退出码 | Exit Code | 程序结束时返回的数字，0 表示成功、非 0 表示出错，脚本据此判断成败（见 02-工具指南/10） |

## F

| 术语 | 英文 | 解释 |
|------|------|------|
| Frontmatter | Frontmatter | 文件顶部的元数据块，用 YAML 写在三引号之间，标记标题、版本等（见 05/06/07） |
| Fork | Fork | 分叉，复制别人的仓库到自己的账号下 |
| Framework | Framework | 框架，软件开发的基础结构 |
| Fine-grained PAT | Fine-grained Personal Access Token | 细粒度 GitHub 访问令牌，可限制到指定仓库和权限 |

## G

| 术语 | 英文 | 解释 |
|------|------|------|
| Git | Git | 版本控制工具，记录代码变更历史 |
| GitHub | GitHub | 代码托管平台，程序员的社交网络 |
| GPT | GPT | 生成式预训练Transformer，OpenAI的语言模型 |
| GitHub Actions | GitHub Actions | GitHub 的自动化工作流系统，可做测试、构建、发布 |

## H

| 术语 | 英文 | 解释 |
|------|------|------|
| Hook | Hook | 钩子，在特定事件（如提交前、命令执行后）触发时自动执行的脚本（见 03-AI协作/08） |

## I

| 术语 | 英文 | 解释 |
|------|------|------|
| IDE | Integrated Development Environment | 集成开发环境，编程用的软件工具 |
| Interface | Interface | 界面，组件之间交互的约定 |
| Issue | Issue | GitHub 上的问题、任务或讨论项记录 |

## J

| 术语 | 英文 | 解释 |
|------|------|------|
| JSON | JSON (JavaScript Object Notation) | 一种轻量的数据格式，用花括号和键值对表示结构化数据（见 02-工具指南/07） |

## L

| 术语 | 英文 | 解释 |
|------|------|------|
| Lint | Lint | 静态检查，自动扫描代码里的格式和潜在问题，不用运行就能发现错误（见 02-工具指南/10） |
| LLM | Large Language Model | 大语言模型，理解和生成文本的AI |

## M

| 术语 | 英文 | 解释 |
|------|------|------|
| MCP | Model Context Protocol | 模型上下文协议，让 AI 工具能即插即用的统一标准（见 05/06/07） |
| Merge | Merge | 合并，把不同分支的代码合在一起 |
| Model | Model | 模型，AI 训练后的「大脑」 |
| Merge Conflict | Merge Conflict | 合并冲突，Git 无法自动决定保留哪一段改动 |

## N

| 术语 | 英文 | 解释 |
|------|------|------|
| Near-miss | Near-miss | 近似命中，AI 答案接近正确但仍有偏差的情况，评测时要单独统计不能算对（见 04-创建Skill/09） |

## O

| 术语 | 英文 | 解释 |
|------|------|------|
| Open Source | Open Source | 开源，代码公开可自由使用和修改 |

## P

| 术语 | 英文 | 解释 |
|------|------|------|
| 路径 | Path | 定位文件或目录的字符串，如 `/home/user/todo.py`，分绝对路径和相对路径（见 02-工具指南/06-07） |
| Plugin | Plugin | 插件，扩展主程序功能的小程序 |
| PR | Pull Request | 请求拉取，提交代码修改供审核合并 |
| Prompt | Prompt | 提示词，给 AI 的指令 |
| Push | Push | 推送，把本地代码上传到远程仓库 |
| Pull | Pull | 拉取，把远程仓库的最新改动同步到本地 |

## Q

| 术语 | 英文 | 解释 |
|------|------|------|
| Query | Query | 查询，从数据库或API获取数据 |

## R

| 术语 | 英文 | 解释 |
|------|------|------|
| Release | Release | 发布，把一个版本正式对外放出的动作，通常附带打包好的产物（见 04-创建Skill/04） |
| Repo | Repository | 仓库，存放代码的地方 |
| Remote | Remote | 远程仓库地址，例如 GitHub 上的仓库 |
| Review | Review | 审查，检查代码质量和正确性 |
| 回滚 | Rollback | 回滚，把代码或版本退回到之前某个稳定状态，用于新版本出问题时（见 04-创建Skill/04） |

## S

| 术语 | 英文 | 解释 |
|------|------|------|
| SDK | Software Development Kit | 开发工具包，编程用的工具集合 |
| 语义化版本 | Semantic Versioning | 语义化版本号，用「主版本.次版本.修订号」表达变更程度（见 04-创建Skill/04） |
| Shell | Shell | 命令行解释器，把你在终端敲的命令翻译给操作系统执行（见 02-工具指南/06-07） |
| Skill | Skill | 技能，给 AI 扩展的能力模块 |
| SSH | Secure Shell | 安全外壳协议，远程连接服务器的加密方式 |
| Stage / Staging Area | Stage / Staging Area | 暂存区，准备进入下一次提交的改动集合 |
| Star | Star | 收藏，给仓库点赞 |
| 符号链接 | Symlink | 符号链接，指向另一个文件或目录的「快捷方式」，操作它等于操作目标（见 02-工具指南/06-07） |

## T

| 术语 | 英文 | 解释 |
|------|------|------|
| Tag | Tag | 标签，给某个提交打的命名标记，常用于标记发布版本（见 04-创建Skill/04） |
| Terminal | Terminal | 终端，命令行工具的界面 |
| Token | Token | 令牌，API 访问的「身份证」 |
| Tracking Branch | Tracking Branch | 跟踪分支，本地分支与远程分支建立对应关系 |

## V

| 术语 | 英文 | 解释 |
|------|------|------|
| Vibe Coding | Vibe Coding | 氛围编程，用自然语言让AI写代码 |
| 虚拟环境 | Virtualenv / venv | 把项目用的库隔离开来的独立 Python 目录，避免不同项目互相污染（见 02-工具指南/08-09） |

## Y

| 术语 | 英文 | 解释 |
|------|------|------|
| YAML | YAML | 一种用缩进表示层级的配置格式，比 JSON 更适合人写（见 02-工具指南/07） |

## Z

| 术语 | 英文 | 解释 |
|------|------|------|
| Zoo | Model Zoo | 模型动物园，AI 模型的集合仓库 |
