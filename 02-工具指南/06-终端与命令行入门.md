# 终端与命令行入门

这篇面向从没在“黑框框”里敲过命令的读者。目标：

**让你敢打开终端，能看懂自己在哪、能安全地列出 / 复制 / 移动文件，听懂“在终端里跑一下”是什么意思。**

---

## 本篇目标

读完你应该能：打开终端；用 `pwd` 说清自己在哪个文件夹；用 `ls` 看到文件（含隐藏文件）；用 `cp` / `mv` 复制移动；理解绝对 / 相对路径和 `.` `..` `~`；知道带空格文件名要加引号；看懂退出码；用 `--help` 查用法；知道哪些命令不能乱跑。

## 前置知识

会用鼠标打开应用、新建文件夹；知道文件夹能层层嵌套。不需要先学 Git，但学完再看 [Git 入门](./01-Git-入门.md) 会顺很多。示例统一标注平台差异（最近核对 2026-07）。

## 核心概念

### 终端、shell、命令

三者分一层：终端是打字的窗口程序；shell 是真正读懂并执行命令的程序（如 `bash`、`zsh`、PowerShell）；命令是你敲的那行指令。不同系统默认 shell 不同：macOS 默认 `zsh`，Linux 多为 `bash` / `zsh`，Windows 默认 PowerShell（老机器上还有 `cmd`）。提示：Windows 装 Git（见 [Git 入门](./01-Git-入门.md)）会顺带得到 Git Bash，体验接近 macOS / Linux。

### 提示符与当前目录

光标前那一串叫提示符，形如 `用户名@电脑名 当前目录 %`；末尾符号因 shell 而异，bash / zsh 普通用户是 `$` 或 `%`，PowerShell 是 `>`。终端永远“站在”某个文件夹里，这就是当前目录。`pwd` 打印你在哪（print working directory）——绝大多数“找不到文件”都是站错了目录。

### 路径

绝对路径从根写完整：macOS / Linux 从 `/` 开始（如 `/Users/maoking/docs`），Windows 从盘符开始（如 `C:\Users\maoking\docs`）。相对路径相对于当前位置，常用三个符号：`.` 当前目录、`..` 上一级、`~` 家目录。切换用 `cd`：

```bash
cd ..       # 上一级
cd ~        # 家目录
cd docs     # 进入子目录
```

Windows 路径用反斜杠 `\`，但 PowerShell 也接受 `/`；跨平台优先用 `/`。

### 退出码

每条命令结束后留下一个数字：`0` 成功，非 `0` 失败。bash / zsh 用 `$?` 查看：

```bash
ls 不存在的文件
echo $?      # 输出 2（失败）
ls
echo $?      # 输出 0（成功）
```

PowerShell 里 `$?` 返回 `True` / `False`，外部程序的数字退出码看 `$LASTEXITCODE`。很多脚本、CI、Git 钩子就靠退出码判断成败。

## 动手步骤

### 第一步：打开终端

macOS 用“终端”或 iTerm2；Windows 搜“PowerShell” / “Windows Terminal”；Linux 各发行版自带。

### 第二步：看位置和内容

```bash
pwd
ls           # 列出文件
ls -l        # 详细列表
ls -a        # 含隐藏文件
```

PowerShell 看隐藏文件用 `ls -Force`。

### 第三步：复制

```bash
cp notes.md notes-backup.md
```

`cp` 默认直接覆盖同名文件、不问确认。PowerShell 的 `cp`（`Copy-Item`）同理。

### 第四步：移动 / 改名

`mv` 既能移动也能改名：

```bash
mv notes.md archive/      # 移动
mv old.md new.md          # 改名
```

### 第五步：练习相对路径

```bash
cd ~
mkdir terminal-demo
cd terminal-demo
pwd
```

### 第六步：带空格的文件名

直接 `cd My Project` 会报错，要加引号或转义：

```bash
cd "My Project"
cd My\ Project
```

建议文件名用英文加连字符（如 `my-project`），少惹麻烦。

### 第七步：查帮助

```bash
ls --help      # 简短帮助
man ls         # 完整手册，按 q 退出
```

PowerShell 用 `Get-Help ls`。

## 常见错误

- `cd: no such file or directory`：路径错或大小写不对。macOS 默认不区分大小写，Linux 区分，养成严格区分最安全。
- 文件名带空格没加引号：回去加引号。
- `command not found`：拼错或没装。
- Windows 下 `/` `\` 搞混：老工具只认 `\`。
- 以为 `cp` / `mv` 会问是否覆盖：默认直接覆盖，重要文件先备份。
- 在错误目录操作：每次先 `pwd`。

## 安全边界（新手必读）

终端几行命令就能删大量文件，记住底线：

- 不跑看不懂的命令，尤其网上复制的、带 `sudo` 的长命令。
- `sudo`（macOS / Linux）和“以管理员身份运行”（Windows）能改系统文件，新手非必要别用。
- 远离 `rm -rf /`、`rm -rf ~`、`rm -rf *` 这类——**不进回收站、永久删除**，`rm` 不给后悔机会。
- 不要把密码 / Token / 密钥当参数明文敲，会被 `history` 记下。
- 陌生目录先 `pwd`、`ls` 看清楚再动手；不确定就先备份。

## 自测题 / 验收

1. 用 `pwd` 说出你在哪个文件夹。
2. 用 `ls -a` 看到一个隐藏文件，解释它为什么以 `.` 开头（答案见 [项目目录与文件格式入门](./07-项目目录与文件格式入门.md)）。
3. 建 `terminal-demo` 文件夹，建 `hello.txt`，复制成 `hello-copy.txt`，再移到上一级。
4. 跑一条失败命令后用 `echo $?` 看到非 `0`，再跑成功命令看到 `0`。
5. 解释 `.`、`..`、`~`。

## 一句话总结

终端入门不是“背几十条命令”，而是：

**敢打开、能定位（pwd）、能看清（ls）、能安全地动文件（cp / mv），并知道哪些命令不能乱跑。**
