## 编号规则

- 每个二级目录独立从 `01` 起编号，按学习顺序排列。
- 新增文章续接当前最大编号；插入文章用 `01a`/`05b` 或重排（重排须同步本表与所有交叉引用）。
- ⏳ 项落盘前先在本表登记编号与「学习结果」，避免与已有篇冲突。
- **03-AI协作与上下文 顺延说明**：实际产出已落在 `08-Prompt-Rules-...-分工`、`09-任务拆解与迭代`，因此「多 Agent 协作入门」「贯穿案例」顺延为 `10`、`11`，不再占用 09。

- 示例项目统一用 `todo.py`（见 `docs/WRITING-GUIDE.md` §4）。
