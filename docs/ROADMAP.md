# 项目路线图

> Last updated: 2026-07-30
> 本文是 starter 仓库的长期规划和阶段进展概览。
> 具体缺陷、验收状态和下一步以 [TASKS.md](./TASKS.md) 为准；文章编号与发布状态以 [CONTENT-MATRIX.md](./CONTENT-MATRIX.md) 为准。

## 项目愿景

把这个仓库做成一个真正可落地的 Skill 开发起点：新人能看懂，开发者能直接复制，团队能长期维护。

## 当前进展概览

- 已建立中文学习资料体系
- 已提供基础模板 `skills/skill-template/`
- 已补齐仓库自身的 `docs/`、`CHANGELOG.md`
- 已汇集多个真实在用 Skill（见 `skills/`），可作为协作文档落地的参考
- 已建立严格 YAML、脚本语法、相对链接和 30 个回归场景组成的统一检查入口
- 已建立与普通提交解耦的每周外链核验，支持有限重试、允许清单和来源定位
- 已让 `skill-template` 支持可验证的最小说明型与带脚本维护型 profile

## 阶段退出条件、依赖与风险

### 阶段一至四（已退出）

仓库已经具备中文学习主线、可复制模板、协作文档、来源与许可证索引，以及本地和 CI 共用的严格检查入口。历史交付内容见 [CHANGELOG.md](../CHANGELOG.md)，关键取舍见 [DECISIONS.md](./DECISIONS.md)。

### 阶段五：标准示例与实测

退出条件：

- 至少有一个 starter 原创示例能在独立目录完成安装、正常执行和错误输入处理。
- 真实 Agent 对该示例完成“应该触发、不应该触发、正常执行、错误输入”四类前向验证。
- 根据示例实测结果决定是否需要增加垂直领域示例，而不是预先批量铺设。

依赖与风险：需要可隔离的真实 Agent 环境；静态检查或当前会话自报不能替代触发验证。具体执行卡见 `TASKS.md` T-007～T-009。

### 阶段六：内容质量验收

退出条件：

- 较早教程按写作规范完成结构复核，参考资料保持索引体裁。
- 核心命令、脚本和示例具有可复跑的行为证据。
- 至少一名零基础真人读者完成顺序走查，卡点修订后有复验结果。

依赖与风险：真人读者时间不可由 AI 替代；不同操作系统和 Agent 版本可能造成结果差异。具体执行卡见 `TASKS.md` T-005、T-006、T-010。

## 阶段六之后的候选方向

以下方向不进入当前任务队列，只有稳定性验收或读者反馈提供依据后再决定：

- 为确有不同教学问题的领域增加示例，避免只更换业务名称。
- 只在关系或流程明显难以用文字理解时增加结构图或流程图。
- 根据走查卡点评估练习答案、FAQ、故障排查索引和文章反馈入口。
- 中文主线稳定并完成验收后，再评估多语言版本。
